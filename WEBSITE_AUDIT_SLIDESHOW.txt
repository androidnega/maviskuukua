4. RECOMMENDED IMAGE SIZES FOR SLIDESHOW
================================================================================

ONE MASTER FILE PER SLIDE (simplest — works mobile + desktop)
--------------------------------------------------------------------------------
  Dimensions:     1200 × 1000 pixels
  Aspect ratio:   6 : 5  (1.2 : 1)
  Format:         JPG (quality 82–88) or WebP
  Color profile:  sRGB
  File size:      Target 150–350 KB per slide (max ~500 KB)

  Why: Matches desktop hero (~1.17:1) and crops acceptably on mobile
       with object-cover centered.


HIGH-RES / RETINA VARIANT (optional second export)
--------------------------------------------------------------------------------
  Dimensions:     2400 × 2000 pixels
  Same aspect:    6 : 5
  Use:            srcset 2x or single sharp source if only one file served


MOBILE-OPTIMIZED VARIANT (optional — faster loads on phones)
--------------------------------------------------------------------------------
  Dimensions:     800 × 900 pixels
  Aspect ratio:   8 : 9  (slightly tall — suits narrow column)
  File size:      80–180 KB
  Use:            <picture> or separate mobile src in slideshow implementation


MINIMUM ACCEPTABLE (do not go smaller)
--------------------------------------------------------------------------------
  Width:          960 px minimum
  Height:         800 px minimum
  Below this:     Visible softness on large desktops and retina screens


ASPECT RATIO — ACCEPTABLE RANGE
--------------------------------------------------------------------------------
  Best:           6:5, 5:4, or 4:3  (landscape to mild landscape)
  Acceptable:     3:2, 16:10
  Avoid:          Ultra-wide 16:9 (heavy side crop in tall mobile box)
  Avoid:          Very tall portrait 2:3 unless subject is centered vertically

  Safe zone: Keep important content in center 70% width × 70% height.


NUMBER OF SLIDES
--------------------------------------------------------------------------------
  Recommended:    4–6 slides
  Duration:       5–7 seconds per slide + crossfade 400–600ms
  Autoplay:       Yes, with pause on hover/focus; manual dots/arrows


FILE NAMING (suggested)
--------------------------------------------------------------------------------
  assets/slideshow/slide-01-community.jpg
  assets/slideshow/slide-02-projects.jpg
  assets/slideshow/slide-03-vision.jpg
  assets/slideshow/slide-04-ahanta-west.jpg
  assets/slideshow/slide-05-membership.jpg

  Alt text: Describe scene + “Mavis Kuukua Bissue” or “Ahanta West” where relevant.


PHOTOGRAPHY TIPS FOR THIS LAYOUT
--------------------------------------------------------------------------------
  • Shoot/export slightly wider than tall; subject centered.
  • Leave ~10% margin on all sides for rounded-corner crop.
  • Consistent color grading across slides (warm, natural light fits brand).
  • Mix: 2 leadership/community, 2 project/event, 1 constituency/landscape, 1 CTA.


TECHNICAL NOTES FOR IMPLEMENTATION (next step)
--------------------------------------------------------------------------------
  • Slideshow replaces single <img> inside the inner rounded div (index.php).
  • Preserve existing heights: min(58vh,440px) / min(62vh,480px).
  • Use same border-radius 1.5rem on each slide.
  • Prefer lazy-load slides 2+; preload slide 1 only.
  • Respect prefers-reduced-motion: show first slide only, no autoplay.
