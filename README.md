# Mavis Kuukua Bissue Membership System

Raw PHP + Tailwind CDN + SQLite membership registration system.

## Run locally

```bash
php -S localhost:8000
```

Open:
- Homepage: http://localhost:8000/index.php
- Register: http://localhost:8000/register.php
- Admin: http://localhost:8000/login.php

Default admin:
- Username: admin
- Password: admin123

## Storage

- SQLite database: `database.sqlite`
- Photos: `storage/photos`
- PDFs: `storage/pdfs`

Make sure PHP can write to the project folder and `storage` folders.
